## 이미지 시안

[시안 목록과 변경 이력](mockups/README.md)에 네 장을 생성 순서대로 정리했다.

현재 참고할 시안은 [04 — 본문 책갈피·우측 기능 아이콘](mockups/04-context-bookmark-icons.png)이다.

- 좌측 회차 검색·범위별 접기와 이전·다음 회차 이동.
- 본문에서 책갈피 추가.
- 우측 텍스트 탭과 빠른 실행 버튼 묶음 제거.
- 우측 상단의 책갈피·조판 아이콘으로 필요한 패널 열기.
- 기존 분량·집필량·회차별 플롯·메모 위젯 유지.

세부 동작과 미정 사항은 이미지보다 최신 TODO 문서를 기준으로 판단한다. 이전 시안의 탭·버튼 구성은 최종 요구 사항으로 취급하지 않는다.
