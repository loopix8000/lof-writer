## 특징

- **로그인 필요 없음**: 귀찮은 가입, 광고, 구독 없이 실행하면 바로 쓸 수 있습니다.
- **로컬 파일 기반**: 원고는 내 PC의 평범한 Markdown 파일로 저장됩니다. 서버에 올라가지 않고, 다른 편집기로도 열 수 있습니다.
- **동기화 지원**: 원할 때만 직접 고른 저장소(로컬·공유 폴더, FTP/FTPS, WebDAV)로 여러 PC의 원고를 맞출 수 있습니다. 별도 서비스 가입은 필요 없습니다.
- **다중 탭 지원**: 여러 문서를 탭으로 열어 두고 오가며 쓸 수 있고, 화면을 나눠 두 문서를 나란히 볼 수도 있습니다.
- **MCP 지원**: Claude, Codex 같은 AI 도구를 MCP로 연결해 원고를 읽고 검색하고 고치게 할 수 있습니다.

## 주요 기능

- **작품 관리**: 작품 소개·태그·표지, 에피소드·위키·메모, 문서 보관과 변경 이력 복원
- **사용자 속성**: 아이콘·속성명·값을 직접 만들고 Markdown YAML에 저장합니다. 설정 → 기본 설정에서 속성 프리셋과 자주 쓰는 태그를 관리할 수 있습니다.
- **집필**: 기본 서식, Markdown 원문 모드, 따옴표·괄호 자동 닫기, 말줄임표와 사용자 대치어
- **화면 구성**: 다중 탭, 두 문서를 나란히 보는 분할 화면, 모바일 미리보기, 집중 모드
- **분량 확인**: 플랫폼별 글자 수, 공백 포함·제외 글자 수, 목표 분량
- **검색과 내보내기**: 제목·본문 검색, Markdown/TXT 내보내기, 본문 텍스트 복사
- **가져오기**: Markdown(`.md`), 텍스트(`.txt`), Muvel 백업(`.mvle`)
- **꾸미기**: 글자 크기·줄 간격, 색 테마(Light Modern, Bakery), 밝게·어둡게 설정
- **외부 연동**: 여러 PC 간 동기화, AI 도구 연결용 MCP와 로컬 API
- **트레이**: 창을 닫으면 트레이로 숨깁니다. 트레이 아이콘을 클릭하면 다시 열리고, 우클릭 메뉴의 ‘종료’로 앱을 완전히 종료합니다.

## 단축키

| 동작 | 단축키 |
| --- | --- |
| 저장 | `Ctrl+S` |
| 검색 | `Ctrl+P` |
| 파일 트리 열기/닫기 | `Ctrl+B` |
| 위젯 보드 펼치기/접기 | `Ctrl+Alt+B` |
| 탭 닫기 | `Ctrl+W` |
| 다음/이전 탭 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 오른쪽으로 분할 | `Ctrl+\` |
| 왼쪽/오른쪽 그룹으로 이동 | `Ctrl+1` / `Ctrl+2` |
| 모바일 미리보기 | `Ctrl+K` 다음 `V` |
| 집중 모드 | `F11` |
| 이름 바꾸기 (파일 트리) | `F2` |
| 보관 / 영구 삭제 (파일 트리) | `Delete` / `Shift+Delete` |

## 주의사항

- Windows PC용이며, 코드 서명은 되어 있지 않습니다.
- 메모·플롯에서는 마크다운 표를 직접 편집할 수 있습니다. 이미지·HTML·링크가 들어간 문서와 에피소드의 표는 원문 모드로 엽니다.
- 자동 저장 전에 PC가 강제로 꺼지면 마지막 입력이 사라질 수 있습니다.
- 같은 문서를 다른 프로그램과 동시에 편집하지 마세요.
- 글자 수는 실제 연재 플랫폼의 등록 화면과 차이가 있을 수 있습니다.
- FTP와 WebDAV는 실제 NAS·서버 환경에서 충분히 검증하지 않았습니다.

## 개발 정보

Tauri 2, Rust, React, TypeScript, Tiptap을 사용합니다.

Node.js 24 이상과 Rust, Tauri 2용 Windows 빌드 환경이 필요합니다.

```powershell
npm ci
npm start
```

프론트엔드 빌드는 `npm run build`, Rust 빌드 검사는 `src-tauri` 폴더에서 `cargo check`로 실행합니다.

Windows 배포본 빌드는 `npm run package`, MSI 생성은 `npm run package:msi`를 사용합니다. 릴리즈와 업데이트 설정은 [RELEASING.md](RELEASING.md)를 참고하세요.
