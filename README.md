# Lof Writer

**Local First Writing Tool** · 1.0.0-beta.1 (Windows)

내 PC에 원고를 저장하는 웹소설 집필 도구입니다. 작품별로 에피소드·위키·메모를 관리하고, 연재 플랫폼에 맞춰 글자 수를 확인할 수 있습니다. 로그인 없이 사용하며, 원고는 다른 편집기에서도 열 수 있는 Markdown 파일로 저장합니다.

## 시작하기

`release/1.0.0-beta.1/win-unpacked/Lof Writer.exe`를 실행합니다. 실행 파일과 같은 폴더의 다른 파일도 함께 있어야 합니다.

1. 처음 실행하면 연재 플랫폼이나 사용자 규칙을 고릅니다.
2. `새 프로젝트`로 작품을 만듭니다.
3. `새 편 쓰기`를 눌러 에피소드를 작성합니다.

입력을 멈추면 자동 저장됩니다. `Ctrl+S`로 바로 저장할 수도 있습니다.

기본 저장 위치는 `문서\Lof Library`입니다. 도서관 화면의 `다른 도서관 열기`로 변경할 수 있습니다.

## 주요 기능

- **작품 관리**: 작품 소개·태그·표지, 에피소드·위키·메모, 문서 보관과 변경 이력 복원
- **집필**: 기본 서식, Markdown 원문 모드, 따옴표·괄호 자동 닫기, 말줄임표와 사용자 대치어
- **화면 구성**: 다중 탭, 두 문서를 나란히 보는 분할 화면, 모바일 미리보기, 집중 모드
- **분량 확인**: 플랫폼별 글자 수, 공백 포함·제외 글자 수, 목표 분량
- **검색과 내보내기**: 제목·본문 검색, Markdown/TXT 내보내기, 본문 텍스트 복사
- **가져오기**: Markdown(`.md`), 텍스트(`.txt`), Muvel 백업(`.mvle`)
- **꾸미기**: 글자 크기·줄 간격, 색 테마(Light Modern, Bakery), 밝게·어둡게 설정
- **외부 연동**: 여러 PC 간 동기화, AI 도구 연결용 MCP와 로컬 API

## 글자 수와 원고 내보내기

노벨피아, 문피아, 네이버 시리즈, 카카오페이지, 사용자 규칙 중에서 선택합니다. 기본 설정 외에 작품별로도 바꿀 수 있습니다. 사용자 규칙에서는 공백·줄바꿈·특수문자 처리와 목표 분량 등을 직접 정합니다.

글자 수는 제목과 Markdown 서식을 제외한 본문을 기준으로 계산합니다. 실제 플랫폼의 등록 화면과 차이가 있을 수 있습니다.

## 백업과 복원

도서관 폴더(`Lof Library`) 전체를 복사하면 원고, 작품 설정, 변경 이력을 함께 백업할 수 있습니다. 백업한 도서관은 `다른 도서관 열기`로 열 수 있습니다.

문서의 이전 내용은 변경 이력에서 복원할 수 있습니다. 영구 삭제하면 문서 파일은 Windows 휴지통으로 이동하고, 해당 문서의 변경 이력은 삭제됩니다.

## 여러 PC에서 동기화하기

`설정 → 외부 저장소`에서 연결을 추가한 뒤 `동기화`를 누릅니다. 함께 사용할 PC마다 같은 저장소 폴더를 지정하세요. 동기화는 버튼을 눌렀을 때 실행됩니다.

| 저장소 | 필요한 정보 |
| --- | --- |
| 로컬·공유 폴더 | 폴더 경로 |
| FTP/FTPS | 호스트, 포트, 계정, 원격 폴더 |
| WebDAV | WebDAV 주소, 계정, 원격 폴더 |

FTPS는 명시적 TLS를 지원하며, SFTP는 지원하지 않습니다.

- 같은 문서를 두 PC에서 수정하면 `(동기화 충돌 사본)`이 남습니다. 두 문서를 확인해 정리하세요.
- 영구 삭제도 다른 PC에 반영됩니다. 다른 PC에서 마지막 동기화 이후 수정한 문서는 삭제하지 않습니다.
- 변경 이력, 가져온 원본, 비밀번호, 편집기 설정은 동기화하지 않습니다.
- 동기화 용량은 장치당 50MB이며, 최대 100대까지 연결할 수 있습니다.

## AI 도구 연결하기

Claude, Codex 등 MCP를 지원하는 도구에서 원고를 읽고 검색하고 수정할 수 있습니다.

1. Lof Writer를 실행합니다.
2. 설정에서 `MCP 설정 복사`를 누릅니다.
3. 복사한 설정을 사용할 도구의 MCP 설정에 등록합니다.

연결 중에는 Lof Writer를 켜 두세요. 앱 폴더를 옮겼다면 설정을 다시 복사해 등록합니다.

직접 API를 연결할 때는 설정의 `API 연결 정보 복사`를 사용합니다. 복사한 정보에는 인증 키가 포함되므로 공유하지 마세요.

## 단축키

| 동작 | 단축키 |
| --- | --- |
| 저장 | `Ctrl+S` |
| 검색 | `Ctrl+P` |
| 파일 트리 열기/닫기 | `Ctrl+B` |
| 위젯 보드 펼치기/접기 | `Ctrl+Alt+B` |
| 탭 닫기 | `Ctrl+W` |

| 오른쪽으로 분할 | `Ctrl+\` |
| 왼쪽/오른쪽 그룹으로 이동 | `Ctrl+1` / `Ctrl+2` |
| 모바일 미리보기 | `Ctrl+K` 다음 `V` |
| 집중 모드 | `F11` |
| 이름 바꾸기 (파일 트리) | `F2` |
| 보관 / 영구 삭제 (파일 트리) | `Delete` / `Shift+Delete` |

## 사용 시 참고

- Windows PC용이며, 코드 서명은 되어 있지 않습니다.
- 표·이미지·HTML·링크가 들어간 문서는 원문 모드로 엽니다.
- 자동 저장 전에 PC가 강제로 꺼지면 마지막 입력이 사라질 수 있습니다.
- 같은 문서를 다른 프로그램과 동시에 편집하지 마세요.
- FTP와 WebDAV는 실제 NAS·서버 환경에서 충분히 검증하지 않았습니다.

## 소스에서 실행하기

Node.js 24 이상과 Rust, Tauri 2용 Windows 빌드 환경이 필요합니다.

```powershell
npm ci
npm start
```

프론트엔드 빌드는 `npm run build`, Rust 빌드 검사는 `src-tauri` 폴더에서 `cargo check`로 실행합니다.

Windows 배포본 빌드는 `npm run package`, MSI 생성은 `npm run package:msi`를 사용합니다. 릴리즈와 업데이트 설정은 [RELEASING.md](RELEASING.md)를 참고하세요.
