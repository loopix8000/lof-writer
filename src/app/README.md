# 앱 구성

`../App.tsx`는 화면 이동과 앱 전체 작업을 관리하고 문서 세션·편집기 그룹·파일 트리를 연결한다.

| 역할 | 모듈 |
| --- | --- |
| 서재·작품 화면 | `LibraryPage`, `ProjectPage`, `ProjectForm` |
| 파일 트리 상태·동작 | `useFileTree`, `file-tree-model` |
| 파일 트리 화면 | `FileTree`, `FileTreeRow`, `MemoFolderTree`, `EpisodeDocList`, `BrokenFiles` |
| 북마크·연결 문서 | `BookmarksPage`, `BookmarkList`, `DocumentLinksWidget` |
| 설정 | `SettingsContent`, `AutocompleteSettings`, `TypesettingSettings`, `settings-pages` |
| 창 제어 | `TitleBar`, `LayoutIcon` |
| 편집기 탭·분할 그룹 | `useEditorGroups` |
| 편집 원고·저장·외부 변경 | `useDocumentSession` |
| 설정 저장 | `usePreferences` |
| 문서 이미지·연결 메모 | `useDocumentImages`, `useDocumentNotes` |
| 문서 캐시·탭·이동 타입 | `model` |
| 문서 유형의 이름·아이콘 | `document-ui` |

화면 컴포넌트는 필요한 값과 동작을 props로 받는다. `FileTree`는 트리 컨트롤러를 받아 폴더별·회차별 문서 목록을 구성한다. 하위 목록은 컨트롤러와 공통 행 렌더러를 사용하고 상태를 직접 변경하지 않는다.

선택·범위 선택, 검색, 폴더·회차 묶음 펼침, 이름 변경, 폴더 이동·삭제와 회차 순서 변경은 `useFileTree`가 관리한다. 위젯의 문서 이름 변경도 같은 이름 변경 상태를 사용한다. 트리에서 편집기로 끌어 놓을 때 `App`은 훅의 드래그 조회·완료 동작을 호출한다. 폴더를 옮기거나 이름을 바꾼 뒤에는 서재를 갱신하고, `App`이 문서 세션의 경로 갱신 동작을 호출한다.

편집 중인 원고·저장 버전, 저장 대기열·임시본, IME 조합과 자동 저장 예약, 외부 변경·충돌 처리는 `useDocumentSession`이 관리한다. 수동 저장과 Git 이력, 이력 복원, 열린 원고의 경로 갱신, 문서별 스크롤과 세션 글자 수의 기준도 여기에 둔다. `App`은 세션의 ref나 상태 setter를 받지 않고 편집·저장·원고 교체 동작을 호출한다.

저장은 메모 세션과 작품 설정의 저장을 기다린 뒤 대기열에서 순서대로 실행한다. 원고 임시본을 먼저 쓰고, 본문 저장과 버전 갱신이 끝난 뒤 임시본을 지운다. 조합 중에는 자동 저장을 미루고 수동 저장·이동을 막는다. 외부 변경을 발견하면 현재 본문을 보존하고, 사용자가 새 내용을 불러오거나 닫을 때 파일의 최신 내용을 채택한다.

파일 위치·회차 순서만 바뀐 경우에는 마지막 저장 원고와 새 파일의 본문·속성을 비교한 뒤 저장 버전을 갱신한다. 입력 중인 원고와 실제 외부 편집은 보존한다. 폴더 이동·이름 변경 중에는 자동 저장과 외부 변경 확인을 기다리게 하고, 새 ID를 세션·탭·분할 그룹·본문 캐시에 반영한 뒤 사라진 탭을 정리한다.

탭 목록·고정·닫기·재정렬, 그룹 분할·전환·크기 조절, 열린 탭의 본문 보관과 비활성 그룹의 외부 변경 확인은 `useEditorGroups`가 관리한다. 문서 ID가 바뀌면 세션이 스크롤·글자 수 기준을 옮긴 다음 `App`의 콜백이 탭·그룹과 이동 기록을 맞춘다.

그룹을 전환할 때는 `App`의 문서 이동 함수가 저장과 읽기를 마친 뒤 `beforeCommit`을 호출한다. 그룹을 맞바꾸고 세션의 `commitDocument`를 동기적으로 호출해 같은 렌더에 반영한다. 마지막 탭을 닫을 때 다른 문서 이동이 시작되면 닫기를 취소하고, 이동이 없으면 세션 초기화와 탭 닫기를 함께 반영한다. 편집기 주변 코드를 변경할 때는 이 순서와 `RetainedTab`의 key를 유지한다.

설정 입력 중인 대치어도 `App`에 두어 설정 창을 닫았다 열어도 남긴다.
